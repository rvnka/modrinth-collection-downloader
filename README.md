# Modrinth Collection Downloader

Batch download a Modrinth collection, right in your browser.

## Usage
Open the [deployed version](https://rvnka.github.io/modrinth-collection-downloader/), or download the repository and open `index.html` locally.

## Files
- `index.html` - page and structure
- `style.css` - Minecraft-inspired theme
- `script.js` - app logic
